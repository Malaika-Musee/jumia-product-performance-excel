# Jumia Product Performance Analysis

This repository contains the raw and cleaned data, pivot tables, and visualizations related to the performance of products on Jumia. It provides insights into sales trends and product metrics for data analysis and reporting.

## Contents
- **Data**: Contains both the raw datasets and the final cleaned versions used for analysis.
- **Analysis**: Includes the Excel workbook with calculated statistics, pivot tables and an interactive dashboard.
- **Visualizations**: Key pivot charts and insights derived from the data.

## How to use
You can download the Excel workbooks to explore the pivot tables, slicers, and charts used to analyze the Jumia product performance.
